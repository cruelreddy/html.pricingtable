# Pricing Table

This repository contains a responsive pricing table component designed for e-commerce and product pages. It provides a clear layout for comparing plan features and pricing, and is optimised for modern browsers and mobile devices.

## Live Demo
[View Live Page](https://sudhakarreddy2005.github.io/html.pricingtable/)

## Overview
The pricing table offers a clean and accessible way to display product plans or service tiers. Each plan card includes pricing, a feature list, and a call-to-action button. The design is focused on readability, responsiveness, and conversion.

## Features
- Responsive layout for desktop, tablet, and mobile.
- Distinct plan cards for easy comparison.
- Clear indication of available features.
- Prominent call-to-action buttons.
- Lightweight HTML/CSS with optional JavaScript enhancements.

## Technology Stack
- HTML5  
- CSS3 (responsive techniques)  
- JavaScript (optional)  
- Hosted with GitHub Pages

## Usage
**View online:** Open the live demo link above.  
**Use locally:**
1. Clone the repository:
   ```bash
   git clone https://github.com/sudhakarreddy2005/html.pricingtable.git
   ```
2. Open `index.html` in any web browser.

## Customisation
- Edit HTML to change plan names, prices, and features.
- Update CSS for colours, fonts, and layout.
- Add or remove plan cards as needed.
